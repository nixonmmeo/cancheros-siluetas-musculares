# Siluetas y músculos — adaptación de «Muscular system» (CC BY-SA 3.0)

Adaptación simplificada de las ilustraciones **«Muscular system»** y **«Muscular system-back»**, de **Termininja**, que el proyecto [wger](https://github.com/wger-project/wger)
incluye en su carpeta `wger/core/static/images/muscles`. Originales en Wikimedia Commons:

- [Muscular system.svg](https://commons.wikimedia.org/wiki/File:Muscular_system.svg) (frente)
- [Muscular system-back.svg](https://commons.wikimedia.org/wiki/File:Muscular_system-back.svg) (espalda)

Las obras originales están basadas, según Commons, en otras imágenes de Wikimedia Commons también bajo CC BY-SA 3.0:
[Pectoralis major.png](https://commons.wikimedia.org/wiki/File:Pectoralis_major.png), [Tibial anterior.png](https://commons.wikimedia.org/wiki/File:Tibial_anterior.png) (Chrizz),
[Gastrocnemius.png](https://commons.wikimedia.org/wiki/File:Gastrocnemius.png) y [Latissimus dorsi.png](https://commons.wikimedia.org/wiki/File:Latissimus_dorsi.png) (original de Chrizz, comprimida por Nikai).

## Qué se cambió

- De cada silueta se conserva solo el trazo más claro (el contorno del cuerpo); se descartan los demás trazos de sombreado.
- Las coordenadas se redondean (1 decimal en las siluetas, 2 en los músculos) y se quitan los metadatos de Inkscape.
- Los músculos resaltados (`musculo-*.svg`) conservan las formas de wger; solo cambian las coordenadas redondeadas y el color de relleno.
- Adaptado el 2026-11-11.

## Archivos

- `frente.svg`, `espalda.svg`: contornos del cuerpo (200 × 370).
- `musculo-<id>-<nombre>-<vista>.svg`: cada músculo resaltado, en el mismo sistema de coordenadas (el id es el de la API de wger). Se dibujan encima del contorno de su vista.
